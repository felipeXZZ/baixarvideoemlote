BAIXA EM LOTE

Rodar no seu PC (para testar e editar)
  1. Precisa ter o Node.js 18 ou mais novo (nodejs.org)
  2. Na pasta do projeto, rode:  npm run dev
  3. Abra http://localhost:3000
  4. Edite os arquivos (index.html, estilo.css, api/*.js...) e dê F5 — não precisa reiniciar

Como colocar no ar (Vercel, grátis)

Opção 1 — pelo terminal (mais rápido)
  1. Abra o terminal dentro desta pasta
  2. Rode:  npx vercel
  3. Responda as perguntas (pode aceitar tudo no Enter)
  4. Para publicar a versão final:  npx vercel --prod

Opção 2 — pelo GitHub
  1. Suba esta pasta para um repositório no GitHub
  2. No vercel.com, clique em "Add New > Project" e importe o repositório
  3. Não precisa configurar nada: clique em Deploy

Arquivos
  index.html     → a página (cola os links, fila, ZIP, um por um)
  api/info.js    → busca os dados de cada vídeo sem marca d'água
  api/video.js   → repassa o arquivo pelo seu domínio (é o que faz o ZIP funcionar)
  dev.mjs        → servidor local do npm run dev
  estilo.css     → cores (tema claro/escuro), menu do topo, botões e rodapé, usados em todas as páginas
  tema.js        → botão de tema claro/escuro (segue o aparelho e guarda a escolha)
  privacidade.html, termos.html, contato.html → páginas do rodapé
  og.png         → imagem que aparece ao compartilhar o link (WhatsApp etc.)
  favicon.svg, apple-touch-icon.png → ícones da aba e da tela inicial do iPhone
  robots.txt, sitemap.xml → para o Google

Antes de publicar, troque:
  - o e-mail SEU-EMAIL@exemplo.com em contato.html
  - o endereço https://baixarvideoemlote.vercel.app pelo seu domínio de verdade, se for outro
    (aparece em index.html, nas 3 páginas do rodapé, robots.txt e sitemap.xml)

Observações
  - A busca usa o serviço gratuito tikwm, que aceita cerca de 1 busca por segundo.
    O site já espera entre um link e outro e tenta de novo sozinho quando bate no limite.
  - Se um dia o tikwm sair do ar, só o api/info.js precisa ser trocado.
  - Abrir o index.html com dois cliques não busca nada: use o npm run dev ou o site publicado.
